# Time Bomb Mobile

Time Bomb Mobile est une adaptation mobile multijoueur du jeu de société **Time Bomb**, développé par Iello. Les joueurs incarnent secrètement Sherlock ou Moriarty et tentent respectivement de désamorcer la bombe ou de la faire exploser.

Le projet vise des parties locales de 4 à 8 joueurs sur Android et iOS, avec une logique de jeu en Rust et une application Flutter.
